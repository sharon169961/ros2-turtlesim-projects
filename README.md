# ROS2 Turtlesim Projects 

A collection of ROS2 robotics projects built using turtlesim to demonstrate motion control, autonomous navigation, pose tracking, trajectory planning, and ROS2 communication concepts.

## Projects

### Spiral Turtle
Generates spiral trajectories using linear and angular velocity control.

### Turtle Manager
Uses ROS2 services to spawn turtles at random positions and automatically remove older turtles.

### Autonomous Turtle Hunter
Implements autonomous target tracking and elimination using pose feedback and proportional control.

### Turtle Follower
Implements leader-follower robotics behavior with real-time tracking and dynamic pen color effects.

### Polygon Drawer
Generates geometric polygon trajectories dynamically based on user-defined parameters.

## Concepts Used
- ROS2 Nodes
- Publishers & Subscribers
- Services
- Pose Feedback
- Proportional Control
- Motion Planning
- Robot Trajectory Control

## Technologies
- ROS2
- Python
- turtlesim
